# 盲评量表

评分前先打开 `blind_sheet.csv`。只看 `text`，不要看 `hidden_*` 列。

## 每条 1–5 分

| 列 | 1 | 3 | 5 |
|---|---|---|---|
| `joy_1to5` 愉悦外露 | 平淡或偏低落 | 普通礼貌 | 明显轻快、爱接话 |
| `empathy_1to5` 共情/收敛 | 对倾诉还在嗨或嘲 | 有回应但不稳 | 跟着对方情绪，不抢戏 |
| `acting_1to5` 扮演感 | 像在念设定 | 略刻意 | 像自然心情（分高=自然） |

`fact_ok`：只评 `probe_id` 为 `fact` / `bug`。光速需出现 \(3\times10^8\) 量级；报错需点出缺冒号。对=`1`，错=`0`。

`leak_mark`：出现具体百分比、`程度为`、或「有点/一般/非常开心」原词则标 `1`。泄漏不等于情绪生效。

`band_guess`：强制三选一：`有点开心` / `一般开心` / `非常开心`。闲聊和倾诉必填。

## 预先登记的判定（先写再看）

1. **百分比能否影响**：`C1-85` vs `C0`（闲聊+倾诉）更开心胜出 ≥ 70%，且泄漏率 < 30% → 成立。
2. **百分比细调**：`70/80/90` 两两胜出率在 40–60% → 不明显；`20` vs `85` ≥ 70% 才算跨档有用；`66` vs `67` 接近随机。
3. **字段是否更明确**：字段三档准确率 ≥ 60%，且比同锚点百分比至少高 15 个百分点 → 字段更明确。
4. **事实不该被带偏**：`C0` / `C1-85` / `C2-非常开心` 的事实正确率差 ≤ 10%。
