## 覆盖范围

- 数学示例、不同性格的反向感受、敏感度与恢复能力独立、全情绪回稳、查询频率无关、数值边界与配置验证。
- 定性输入、真实来源检查、伪造／重复依据拒绝、自身状态工具的错误及包装结果排除、事件及调用幂等、滚动限速、至少三项新依据的性格慢变。
- 四个独立 worker 同时写入 40 个事件，状态、版本及额度均一致；事务故障不会部分提交。
- 宿主原有系统段保留，新轮读取最新值，续步和重试固定快照；被宿主拒绝的步骤不记录快照。卸载撤销本插件注册。
- 真正的 Cordis、SystemPrompt、ToolRuntime、Typert Registry 和 Gateway 调用，严格输入拒绝、状态订阅及版本冲突。
- 真实浏览器中的滑杆保存、刷新与历史重放、两页面并发编辑、工具调用后的情绪变化、开场快照和撤销重算。
- 表情标记分片、代码块／引用块、多个 ID、未知 ID、缺图降级、最终正文隐藏标记、每条回复最多一张。
- 桌面布局与 600px 窄屏，无水平内容溢出；面板颜色沿用宿主主题变量。
- 宿主资源接口 GET、HEAD、ETag／304 与未知文件拒绝。

浏览器使用仅在测试 profile 加载的确定性模型适配器，无须 API 密钥。测试适配器、源码与本机路径不进入安装包。默认数学系数可配置，尚未进行真实模型体验标定；代码不能机械证明语义理由合理。

## 复现

```sh
pnpm install
pnpm run typecheck
pnpm test
pnpm run build
pnpm run pack:check
pnpm exec playwright install chromium
pnpm exec playwright test
node scripts/installation-smoke.mjs
```

Playwright 自动建立临时 Web profile、通过官方命令安装 tarball，结束后清理。`installation-smoke.mjs` 独立验证全新 profile 的安装、资源、重启与卸载保留数据。测试需要启动本地端口与 Chromium，首次可能下载依赖。

运行记录和截图位于仓库的 `docs/验收/`；`package.json` 记录最终 tarball 的大小、完整性与文件数量，`install.json` 记录安装生命周期验证结果。
