# 安装与使用

插件 0.1.5，兼容 DSH 0.2.1-rc.2 / 0.2.1-rc.3。使用官方 bundle 安装，不修改宿主源码。要求 Node.js 22.19 以上的 22.x 或 24+，以提供内置 SQLite。

## 安装

下载 `dsh-mood-0.1.5.tgz`，在已初始化的 Web profile 中运行：

```sh
dsh plugin --profile web add ./dsh-mood-0.1.5.tgz
dsh web
```

首次初始化 profile 可运行 `dsh web --help`。安装时包管理器可能下载运行依赖；Host、Client 和图片已预构建，不需要本机源码、TypeScript 编译器或第三方 SQLite 原生扩展。

桌面 App 请使用 App 附带的命令安装到 `desktop` profile，随后重新打开 App。macOS 安装命令：

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add ./dsh-mood-0.1.5.tgz
```

桌面图片由模块 C 的只读 Remote 接口经 IPC 返回，不要求启动 Web 服务器；Web 版继续使用图片资源路由。两种模式均不增加模型工具、不改写角色状态。

## 日常使用

- 每轮用户消息开始时注入数值，本轮工具续步不重写系统提示词。
- 模型判断有实际依据时调用 `mood_update_emotion` 或 `mood_update_personality`；没有工具调用，就没有事件引起的数值变化。
- 从侧栏“搭档状态”查看五项情绪、七项性格雷达图和历史；点击相应“编辑”按钮打开滑杆弹窗，保存时只提交修改项。遇到版本冲突时保留草稿，可重新载入当前状态。
- 在“变化规则”中分别设置情绪、性格的单事件上限、滚动时间与每项累计上限。时间可选秒、分钟、小时、天，额度支持小数；点击保存立即生效，取消不提交，恢复默认只填入草稿。额度设为 0 会暂停对应自动更新，手动编辑和自然回稳不受限制。
- 一个真实事件即可支持微量性格成长；默认轻微、明显、强烈分别为 0.01、0.025、0.05 点。同一依据不能重复改变同一属性。
- “开场快照”可选择会话，查看最近一轮实际注入的提示词，与当前共享状态对照。
- 情绪事件旁的“这次理解错了”会撤销该判断，按时间线重算后续情绪与额度。有关联的性格依据标记待复核，已有性格慢变暂保留。
- 模型可在最终回复末尾写 `[dsh-mood-sticker]: smile`。每条最终回复最多显示一张，代码块中的示例不触发。

## 数据与配置

数据默认存于 `<profile>/data/dsh-mood/mood.sqlite`，例如 `~/.dsh/profiles/web/data/dsh-mood/mood.sqlite`，不写入聊天工作目录。备份时停止宿主后复制整个数据目录。卸载会撤销工具、提示词段、面板和资源路由，保留数据目录。

在该 profile 的 `cordis.patch.yml` 中合并[配置示例](配置示例.yml)，重启宿主生效。配置支持初始性格、公式权重、增益和半衰期；限制规则仅首次从配置导入，之后以页面保存的 SQLite 设置为准，重启不会覆盖。开发时详见 `src/core/config.ts` 的 `DynamicsConfig`，安装包中对应 `lib/core/config.d.ts`。修改初始配置不会覆盖已有状态，日常调整请使用编辑弹窗。

默认性格均为 0。情绪从对应基线开始；恢复能力影响全部情绪。内部保存浮点数，雷达图的情绪最多展示一位小数，性格最多三位。显示面板每 30 秒重新读取时间投影，读取不保存事件、不占额度；轮内开场提示词保持固定。

## 验证与排查

- 出现数据库错误时，插件会明确失败，不创建一份零值状态来掩盖异常。保留原数据后排查权限或损坏原因。
- 工具拒绝会返回原因和当前状态；基础设施故障使用宿主标准工具错误通道。
- 情绪的语义判断依赖模型。代码保证公式、来源检查、去重和限速，无法机械验证每个理由是否合理。
- 原始表情目录为 `stickers/catalog.json`，安装包中的图片位于 `lib/assets/`。浏览器资源加载失败时正常文字仍可见。

开发命令与测试覆盖见[验收记录](验收记录.md)。
